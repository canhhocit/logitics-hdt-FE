# HDT Logistics Website

Website chính thức của Công ty Cổ phần HDT Logistics – "Kết nối hành trình, vươn tới tương lai"

## Công nghệ sử dụng

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Lucide React** (icons)

## Cấu trúc trang

| Trang | Route |
|-------|-------|
| Trang chủ | `/` |
| Giới thiệu | `/about` |
| Dịch vụ | `/services` |
| Chi tiết dịch vụ | `/services/[slug]` |
| Tin tức | `/news` |
| Chi tiết tin tức | `/news/[slug]` |
| Tuyển dụng | `/careers` |
| Chi tiết tuyển dụng | `/careers/[id]` |
| Liên hệ | `/contact` |
| Tra cứu vận đơn | `/tracking` |
| Chính sách bảo mật | `/privacy` |

## Cài đặt và chạy

```bash
npm install
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000)

## Build production

```bash
npm run build
npm start
```
